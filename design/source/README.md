# Design source files

These are the original design files. They run only inside the design tool, so use them as reference:

- **Markup and styles:** the HTML at the top of each file has the exact copy, section order, colours and spacing for every screen.
- **Sample data and behaviour:** the script at the bottom (`class Component …`) holds the sample data and the prototype's behaviour. Examples: request statuses, permissions per role, what each button does, and the lead actions.
- `portal-and-team-panel.dc.html` contains the client portal and the team panel. Screens switch on values like `on.dash`, `on.aticket` and `on.demo`.
- `website-*.dc.html` are the 11 website pages. `Light` is the Home page.

The prototype's "VIEW AS" switcher and the fixed "Monday, 9 November" date are design-only. Don't copy them into the app.
